# TT-Agent-Plus-727 全屏响应式布局设计

## 目标

将现有居中弹窗改为覆盖整个 TauriTavern 视口的插件工作区，同时为 PC 和手机提供符合各自操作习惯的导航与内容布局。此次仅调整插件主界面外壳和响应式布局，不实现审核弹窗、灵动岛或审核流程。

## 设计原则

- 插件打开后完全覆盖 TT 视口，关闭后返回 TT。
- PC 与手机共用同一套语义 DOM、状态和事件，仅通过 CSS 响应式布局切换。
- PC 优先支持高密度、重复操作；手机优先保证触控、可读性和单列编辑。
- 页面不得产生横向滚动，只有手机顶部标签栏允许横向滚动。
- 保留现有中文界面、深浅主题、魔法棒入口和 `/777` 命令。
- 不提前为审核弹窗或灵动岛添加占位结构。

## 整体外壳

插件根节点固定覆盖视口：`position: fixed; inset: 0`，使用动态视口高度并兼容传统视口单位。全屏状态下移除居中弹窗的外边距、圆角、阴影和缩放效果，不再表现为悬浮卡片。

外壳由三个稳定区域组成：

1. 产品导航区。
2. 当前页面标题与操作区。
3. 可独立滚动的页面正文区。

打开和关闭只使用约 180ms 的透明度与轻微位移动画。启用 `prefers-reduced-motion` 时取消位移动画。

## PC 布局

断点为 `min-width: 721px`。

- 左侧固定导航宽度约 208px，占据完整视口高度。
- 导航顶部显示产品名称 `TT-Agent-Plus-727`。
- 六个主入口纵向排列：总览、任务、规则、缓存、调试、设置。
- 每个入口使用已有图标体系配合中文标签，并通过背景、边框和文字对比表示当前页面。
- 导航底部放置主题状态和关闭按钮。关闭按钮仍使用熟悉的关闭图标并提供可访问名称。
- 右侧工作区使用 `minmax(0, 1fr)` 占据剩余宽度。
- 工作区顶部显示当前页面标题与该页面的必要操作；正文填满剩余高度并独立滚动。
- 规则编辑等复杂页面可以使用列表与编辑区双栏，宽度不足时允许内部网格收缩，但不允许整个页面横向溢出。

## 手机布局

断点为 `max-width: 720px`。

- 顶部标题栏固定显示产品名和关闭按钮。
- 标题栏下方固定显示六个主标签，保持单行并允许横向滚动。
- 标签不折行、不压缩成不可读文字；当前标签始终具有清晰选中状态。
- 页面正文位于导航下方并独立纵向滚动。
- 双栏页面改为单列；列表与编辑器按阅读顺序排列。
- 工具栏允许合理换行，搜索框优先占满一行，触控按钮保持稳定尺寸。
- 使用 `env(safe-area-inset-top/right/bottom/left)` 适配刘海屏、状态栏和底部手势区域。
- 390px 宽度下不得出现页面级横向滚动、按钮文字截断或控件重叠。
- 横屏和软键盘导致可用高度变化时，使用动态视口高度保持标题、导航和正文滚动边界正确。

## DOM 与状态边界

PC 和手机不得维护两套渲染树。`renderPanelHtml()` 生成一套稳定外壳，CSS 根据断点调整网格区域、导航方向和内容排列。

页面切换仅更新当前页面区域，不应因为布局切换而重置业务状态。输入中的规则名称、搜索条件、复选状态、正文滚动位置和活动标签不得因窗口尺寸变化而丢失。

现有 `mountPanel()` 回调契约保持不变。全屏布局不改变设置、缓存、任务或世界书规则的数据结构。

## 滚动与层级

- 插件外壳本身不滚动。
- PC 左侧导航固定；右侧正文滚动。
- 手机标题栏和标签栏固定；正文滚动。
- 世界书条目列表、调试日志等已有高密度区域继续使用内部滚动。
- 禁止正文滚动容器与页面根节点形成无意义的双重滚动。
- 插件层级继续高于 TT 导航和聊天界面，但不改变宿主的永久样式。

## 视觉与主题

- 沿用现有深色、浅色和跟随系统主题变量。
- 保持现有青绿色强调色，并继续使用中性色、警告色和危险色区分状态。
- 全屏页面区块不包装成层层卡片；卡片仅用于任务、缓存记录等独立重复项。
- 字号不随视口宽度缩放，字距保持为 0。
- 所有文本容器设置可靠的收缩与换行规则，避免长角色名、规则名和调试信息撑破布局。

## 动画

- 打开：透明度从 0 到 1，并从 6px 轻微位移归位。
- 关闭：执行相反动画后隐藏交互。
- 页面切换不使用大幅滑动，仅允许短暂淡入。
- 悬停和选中状态使用颜色、边框和背景过渡，时长不超过 180ms。
- `prefers-reduced-motion: reduce` 下取消位移和非必要过渡。

## 可访问性

- 主导航继续使用 `tablist`/`tab` 或等价的明确语义，并维护 `aria-selected`。
- 关闭按钮有中文 `aria-label`。
- 键盘焦点在打开插件后进入当前工作区；关闭后尽量归还给触发入口。
- 所有焦点状态在深浅主题下均清晰可见。
- 手机横向标签栏可通过触控、键盘和滚轮访问全部入口。

## 错误与降级

- 不支持动态视口单位时回退到 `100vh`。
- 不支持 `backdrop-filter` 不影响可用性；全屏布局不依赖模糊效果。
- 宿主文档 API 缺失时继续沿用现有软失败策略。
- 旋转屏幕或调整窗口时仅触发 CSS 重排，不重新创建应用实例。

## 验收标准

### 自动测试

- 渲染结构包含全屏外壳、PC 导航区、页面标题区和正文区。
- 六个标签和现有回调契约保持完整。
- CSS 包含 PC 左侧导航和 `max-width: 720px` 手机顶部导航规则。
- 移除原居中弹窗尺寸、居中变换、外边距和圆角依赖。
- 深浅主题、关闭操作、标签切换和现有业务测试全部通过。

### 浏览器视觉测试

- PC：1440x900、1280x720。
- 手机：390x844、360x800。
- 手机横屏：844x390。
- 验证全屏覆盖、导航位置、页面滚动、长文本、双栏/单列切换和无横向溢出。
- 验证搜索框连续输入不会丢失焦点或光标。
- 验证深色、浅色和减少动画偏好。

### TT 实机测试

- 魔法棒和 `/777` 均打开同一个全屏界面。
- 插件完全覆盖 TT，关闭后 TT 原界面可正常继续使用。
- 安卓软键盘弹出和收起时，当前输入框与操作按钮保持可访问。
- 不出现审核弹窗或灵动岛相关占位元素。
